GlobalId IRIs

Nodes of Tectonica layer files are identified by IRIs of the form https://w3id.org/tectonica/guid/<GlobalId>, where the GlobalId is the 22 character IFC GlobalId of the element (or a GlobalId derived from a semantic path for records that are not IFC elements). There is no central registry: an IRI names a node inside the model files that use it, and resolves to this page.
