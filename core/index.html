Tectonica core ontology

Version 0.1. IRI https://w3id.org/tectonica/core, prefix tec:. License CC BY 4.0. Download: Turtle (latest), Turtle 0.1.

An ontology of parts for architecture and the built world. Physical elements form the base layer; rooms and other human definitions are abstractions laid over it; components, containers, material states and provenance are separate logical layers that refer to the same element identifiers.

153 classes, 88 properties, 20 named individuals. Aligned to BOT; IFC 4.3 class names are given per class.

Asserted passage tec:AssertedPassage

A connection between spaces stated in the layer file, by a rule or a person, where the IFC file has no door, opening or stair that shows it: an open plan boundary, a missing wall, a ladder or a hole in a ruin. Kept apart from passages derived from IFC so the two can be compared. Not matter.
